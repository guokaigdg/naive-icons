# 图标质量硬标准（自检清单）

本清单用于 naive-icons 新增与重绘图标的逐枚验收。每条都要在 16 / 24 / 48 三档渲染后人工确认，
不能只看源码。检查顺序：先看 16px 的剪影，再看 48px 的结构，最后回看 24px 的整体比例。

## 六条硬标准

- [ ] **1. 不用基础图元硬拼形体。**
  禁止「三角形当屋顶 + 半圆当机身 + 两个圆当轮子」这类积木式拼装。主体轮廓必须用有意图的
  路径/曲线表达形体转折（颈、喙、鳍、衣褶、器械外壳的收腰），让人看不出图元接缝。
  判定：把图标缩到 16px，若还能一眼数出「这里是个圆、那里是个三角」，即不合格。

- [ ] **2. 比例经过设计判断。**
  主体尺寸、留白、重心要有取舍；同一分类内视觉体量一致（不得一枚瘦长、一枚矮胖）。
  判定：把同分类 6 枚并排，主体的「墨水面积」落在一个可视的窄区间内。

- [ ] **3. 线宽与圆角语言统一。**
  继承根节点的 3.5 墨色描边；内部结构线用 2–3；小色块按需显式 `stroke-width`。
  同一枚内不混用「全圆角」与「全直角」两种转角语言。
  判定：48px 下所有外轮廓的转折半径看起来属于同一支笔。

- [ ] **4. 负形有功能。**
  镂空、缺口、留白必须承担分隔结构或暗示材质的作用，不能靠细碎小点凑细节。
  判定：删掉任意一处留白，语义会变差；若删掉后无差别，这处留白就是废细节。

- [ ] **5. 16px 可辨优先。**
  每枚必须在 24px 与 16px 下读出语义。一个概念若 16px 下必然糊，换更好读的角度画，
  而不是硬交一枚小尺寸废掉的图标。主要语义特征（颈长、喙、尾、天线、把手）要占主体比例。
  判定：16px 白底渲染后，不看名字能把该图标归到正确分类。

- [ ] **6. 硬规范不变。**
  48×48 画布；根节点与全库逐字节一致；仅用 10 色白名单；描边外缘距边 ≥ 3；
  小面积填充显式 `stroke="none"`；body 顶格、`</svg>` 独占末行、文件末尾无换行。

## 流程

1. 每批先画 10 枚试点（3 静态物 + 3 动物 + 2 设备 + 2 表情），渲染 16/24/48/72 自评。
2. 试点不达标就改画法或收窄概念，达标后再按 50 枚一批推进。
3. 每批完成即渲染联系表，按本清单逐条打勾；有不合格项先修，再开下一批。
4. 重绘只改确认仍偏弱的图标，保留 id 与语义；`id`、`stroke` 继承、边距三项回归测试必须全绿。

## 常见不合格模式（反例）

- 半圆机身 + 三角尾翼的「拼装飞机/船」。
- 用 3 个 1.5 半径小圆当「细节」，16px 直接消失。
- 主体贴边到 3.0–3.5 外缘，24px 视觉上顶格。
- 同一枚里既有 2 半径圆角又有直角矩形。
- 只靠颜色区分语义（如两个都是圆，只换填充色）。
