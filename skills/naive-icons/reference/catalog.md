# naive-icons 全量目录

> 本文件由 `scripts/build_skill_assets.py` 生成，不要手改。
> 新增图标后重跑该脚本，否则 `search.py` 仍能命中（索引内嵌在脚本里），
> 但本目录会缺项。

组件名规则：连字符分段首字母大写 + `Icon`，如 `user-plus` → `UserPlusIcon`。
